Change an existing image in the workspace with the user's image model. paths are 1-4 workspace paths; the first one is the picture to edit, the rest are references (style, subject, an object to add). The brief should say exactly what changes and what stays the same. The result is written under /workspace/out/images/ and, when the current model can see images, shown to you for checking. Editing a photo the user attached uploads it to the image service: do this only when the user asked for that edit. Each image costs money. If the model cannot edit from references, this tool is not offered; use image_generate instead.
