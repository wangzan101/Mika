Insert 1-100 events into a visible writable Android calendar in one provider batch, without opening a calendar screen. Prefer this over repeated phone_add_calendar_event calls for 3 or more events. Every item has the same fields as phone_add_calendar_event: title and start are required; end, allDay, location and description are optional. start and end are local date-times like 2026-11-02T14:30; for an all-day event give dates like 2026-11-02 with allDay=true. All items are validated before any write. Success means the provider returned one valid event id per item.

If calendar_permission_required is returned, nothing was written: use phone_add_calendar_event and save through the calendar UI, or ask the user to grant calendar access in Android settings. If no_writable_calendar is returned, use the calendar UI or ask the user to enable a writable calendar. If calendar_write_unconfirmed is returned, some events may already exist: do not retry the batch or insert them through another path until the calendar has been checked for duplicates.
