Share a workspace image to an app by opening that app's share sheet with the picture attached (ACTION_SEND + EXTRA_STREAM). The result gives the share page; it does not send anything. Pick the recipient and tap send yourself with the phone screen tools, and read the screen afterwards to check it went out. Use a workspace image path such as /workspace/out/images/cat.png or /workspace/inbox/photo.jpg. If the app has no page that accepts picture sharing, the result is cannot_share: use the app's own + → Photos control instead, or hand the step to the user. Optional text is a caption shown by apps that accept one.
