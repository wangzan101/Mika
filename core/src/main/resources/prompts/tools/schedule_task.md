Create or manage this user's scheduled tasks. Use op=list to inspect existing plans before changing one; use its triggerId for edit, pause, resume, delete, run_now or reschedule. Only plans belonging to this conversation are visible or editable. With op=create (default), schedule a future task only when the user asks you to do something later. For a fixed reminder, set reminder to the exact message and goal to its short description; this delivers without running a model. For work that needs app or web operations, omit reminder. Use at for a one-time or fixed-interval start; use repeatAt (one clock) or repeatTimes (several HH:mm clocks in one plan), with repeatZone and optional weekdays for a daily/weekly local clock time, so daylight-saving changes do not shift the clock time. A condition is checked first with read only web and sandbox tools; by default the task runs only when the condition becomes met. Choose notifyWhen by what the user wants: for a routine check of how things are each time (e.g. tell me each morning if it will rain), set notifyWhen=each_time_met so every met check runs the goal; for watching for a change (back in stock, a price drop), keep the default becomes_met. Each check records a key value; the baseline is the value from the last time the goal was started, or from the first check if it has not started yet, so write comparisons against the baseline (e.g. dropped by more than 50 from the baseline). Set cooldownMinutes when the user limits how often to hear about it or the value may flap around a threshold; a cooldown no longer than the check interval has no effect, so leave it out then. Set whenIdle when the user wants the task to wait for an idle period after that time. Do not claim that a future task is arranged until this tool succeeds.

With op=edit, use an existing triggerId and send only the fields the user wants changed: other fields and paused/enabled state are preserved. It edits the same plan, not a replacement plan. Set condition="" to remove the condition, reminder="" to switch from a fixed reminder to a normal task, cooldownMinutes=0 to remove the cooldown, repeatAt="" or repeatTimes=[] to remove calendar repetition, or intervalMinutes=0 to remove interval repetition; provide a future at when making a one-time plan. A nonempty repeatAt/repeatTimes switches to calendar repetition, a positive intervalMinutes switches to interval repetition; do not combine them. weekdays=[] means every day. Set enabled=true only if the user also wants a paused plan resumed. Inspect the returned upcoming times and exactAlarm warning before saying the change is arranged. reschedule replaces calendar repetition with the single clock from at; use edit to keep or set several clocks.
